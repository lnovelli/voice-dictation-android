# Model installation and ASR validation

## Model catalog and safe extraction

Inspect `ModelInfo`, `ModelManager`, preferences, Settings, readiness/delete and all live, file and History dispatch paths together. Initialize before capture or buffer all audio while loading. Check the exact release asset name, size, contents and digest against the authoritative release listing; validate user-supplied names literally, never silently repair them.

For an ASR regression, compare old and current code and uncommitted changes, model URL/checksum, runtime, persisted decoding options, audio preprocessing and final text rules. A reused preference may start affecting a model it previously bypassed. When authorized, compare the same recording and settings; distinguish code inspection from measured device behavior.

`ModelManager` stages downloads in unique app-private directories and verifies a SHA-256 when specified by the catalog. Admit exactly the four expected filenames under the model root, ignore other entries without resolving their paths, and reject duplicates, missing entries, malformed headers and non-regular file types. Commons Compress `isFile()` is insufficient: require `TarConstants.LF_NORMAL` or `LF_OLDNORM` explicitly. Verify staged files before install; preserve existing model directories including partial ones, restore on failed swap where possible, and clean staging on failure/cancellation. Do not silently delete older user models as a selection migration. Model storage is under app-private `filesDir/models`; do not assume ordinary file managers can access it.

Fluid Speech Pro by FluidVoice ([model card](https://huggingface.co/FluidVoice-Labs/fluid-speech-pro-onnx), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)) uses the official sherpa split INT8 ONNX conversion, based on NVIDIA Parakeet TDT 0.6B v3 and Moondream Parakeet Ultra. Its seven direct files are pinned to Hugging Face revision `fa588e9f87f1b9ad0ca2e2d8f7eaf84dc3803581`: the three graphs, their adjacent `.onnx.data` weights and `vocab.txt` (not `tokens.txt`). Catalog sizes and LFS SHA-256 values come from the Hugging Face model API; the Git-managed vocabulary SHA-256 is calculated from the pinned file. Download into a unique staging directory over HTTPS, reject non-HTTPS redirects and size mismatches, and verify each file's digest before swapping into place. Readiness checks exact file sizes, not a full rehash at every settings refresh. Cancellation or failed validation removes staging and keeps the previous installation. The model detects 25 European languages, is offline/post-stop, has no live preview, and recordings longer than 30 seconds must use fixed chunks rather than a new VAD. ASR behavior and native/device compatibility require separate validation.

## Streaming and vocabulary

The app uses Nemotron streaming through the packaged sherpa-onnx runtime. Keep endpoint resets disabled when Stop is user-controlled. Language defaults to automatic detection; Settings also offers the model's transcription-ready and broad-coverage locales, with exact prompt codes and a warning that broad coverage has higher error rates. Snapshot the choice once per session and set the online stream's `language` option before its first waveform, including file, History and remote PCM paths. Fluid Speech Pro has no language-conditioning input and remains automatic; ML Kit has its own explicit locale. A Nemotron prompt steers recognition, not a guarantee of output language or accuracy. Finalization padding is separate from original audio; a past host experiment's 1.28 s tail matched a 2.4 s control at three shifts of one English sample, not proof of universal flush or Android performance. ML Kit GenAI Speech Recognition Advanced is an independent optional engine; consult [Google's documentation](https://developers.google.com/ml-kit/genai/speech-recognition/android), check the exact advanced configuration and locale with `checkStatus()`, and handle all four statuses. A downloadable model is not inference-ready. Never fall back to Basic without explicit user intent.

For vocabulary work distinguish acoustic decoder bias from text-only spelling and replacement. Sherpa-onnx 2.0.1 supports streaming NeMo modified beam search and hotwords; this acoustic bias is Nemotron-specific. Bias can change unrelated words or produce hallucinations, so retain an unbiased default and do not claim accuracy guarantees. When evaluating, compare bias on/off on the same human-reference targets and negatives, including silence, noise, pauses and continuous speech; label synthetic/TTS samples honestly. Host inference is not phone lifecycle or performance validation.
