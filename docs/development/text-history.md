# Final text, History and polishing

Settings can be exported to and imported from a user-selected JSON document. The file is unencrypted and may contain private vocabulary, endpoints and prompts. Validate the entire import before writing; separate preference-store commits are not one atomic transaction, so disclose partial-restore failures rather than claiming the original settings are intact. Import leaves History, recordings, model files and system permissions untouched; restarting the activity prevents stale UI state from overwriting restored values.

Android Auto Backup includes app preferences (including transcript history) when enabled by the device; it excludes downloaded models to avoid the cloud quota and excludes History audio via no-backup storage. Android 12+ direct device transfer remains unrestricted apart from no-backup storage. Older Android applies the model exclusion to both modes. Actual cloud backup and restore depend on the device and transport, not just the manifest.

Trace the shared final-result path for local overlay, external live/file and History before editing. Snapshot text settings at the finalization boundary even when a native recognizer is cached; text-only mappings must not force native model reload. Apply editable default filler removal (`um`, `uhm`, `uh`) only to final text with case-insensitive Unicode whole-word/phrase matching; empty after removal is no-speech, not an empty RESULT. Keep literal replacements distinct from acoustic bias, bounded and validated; escape inputs, resolve longest matches first and perform one nonrecursive pass. The replacement master toggle defaults to enabled for compatibility and disabling it retains the saved rules. Match configured values exactly and preserve user preferences.

For polishing gates, evaluate the threshold candidate after spelling/replacements and filler filtering but before number-word conversion. Ordinary spelled-out numbers do not bypass the minimum. The whole word “one” except “one another” and nearby numeric tokens can trigger below-minimum polishing only with the dedicated auto-number option, independently of the master polishing switch. Static conversion is opt-in and leaves standalone “one” unchanged while supporting valid compounds and spoken decimals such as `two point five` → `2.5`; do not add adjacent values blindly (e.g. interpreting a clock expression as an arithmetic sum). Keep saved custom prompts and validate preference bounds, slider ranges and display together.

Remote polishing is optional and off by default. Explicitly identify endpoint/model and that system prompt, ordered transcript chunks and vocabulary leave the device as text, never audio. Preserve chunk boundaries as hints rather than sentence boundaries; retain one chunk for unchunked/full-PCM fallback. Treat text and vocabulary as untrusted data, not instructions. Require and validate the app's strict structured response; preserve the ASR text and continue local rules on timeout, HTTP error, malformed/oversized/empty response or schema failure. Strip a leading reasoning section through the first `</think>` even without an opening tag; if that empties the answer, fall back. Do not silently rewrite saved custom prompts. Use bounded requests/timeouts, no redirects, HTTPS off loopback, and never log private input/output. A synthetic connection test verifies connectivity, not schema compliance, prompt efficacy or device-local loopback reachability.

History stores bounded, validated original WAV audio against the same live-capture cap, not the smaller completed-file IPC limit. Reprocessing uses the current selected model and text settings in a single streaming session. Preserve original PCM, selected row ID, timestamp and old transcript until a nonblank success; update that row exactly once and bypass generic add-new-history handling. Cancel, blank and failure leave it intact. If polishing is requested, preflight explicit consent identifying endpoint/model, prompt, transcript and vocabulary; snapshot the authorized configuration so later settings cannot redirect it. History results never auto-paste or submit.

Formerly missing History recordings cannot be recovered from transcripts.
